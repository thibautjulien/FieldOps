# 🚧 FieldOps

> Application mobile de gestion d’interventions terrain (agents & entreprises) pour pouvoir compléter ma formation en tant que développeur web et mobile.

---

## 📱 Aperçu

**FieldOps** est une application conçue pour faciliter la gestion des interventions sur le terrain.

Elle permet aux entreprises et collectivités de :
- 📋 Gérer les interventions
- 📍 Suivre la géolocalisation
- 📸 Ajouter des photos avant/après

---

## ⚙️ Stack technique

### 🖥️ Backend
- **Node.js**
- **Express**
- **SQLite** (dev)
- **JWT** (authentification)

### 📱 Mobile
- **React Native**
- **Expo**

---

## 🚀 Fonctionnalités

- 🔐 Authentification sécurisée (JWT)
- 👤 Gestion des utilisateurs
- 📌 Création et suivi des interventions
- 📸 Upload de photos (avant / après)
- 📝 Historique des actions (logs)
